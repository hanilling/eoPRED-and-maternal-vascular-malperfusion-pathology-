# A placental DNA methylation score for EOPE and MVM pathology
This respository contains code from the paper [A placental DNA methylation score associated with early-onset preeclampsia and maternal vascular malperfusion pathology](https://doi.org/10.3389/freae.2026.1749513) (Frontiers in Epigenetics and Epigenomics, 2026). It involves testing for an association between eoPRED score, placental cell estimates, and placental histopathology.
<img width="1400" height="788" alt="Graphical_Abstract2" src="https://github.com/user-attachments/assets/f05d9495-3161-47e3-a8dd-cdcb91a21171" />


The **Stress Pregnancy and Health (SPAH)** dataset was used and is available at [GSE307289](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE307289). Additional pathology information is available upon request to the authors. 

Code pertaining to the initial processing of this dataset can be found [here](https://github.com/hanilling/DNA_methylation_profiling_of_placental_histopathology-).

The function to calculate **eoPRED score** is available in the [PlaNET R package](https://doi.org/doi:10.18129/B9.bioc.planet).
